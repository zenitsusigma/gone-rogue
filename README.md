You will build your Python game in this repository. The game is based on the proposal you have provided in Assessment Task 2.

You are to log your work in the Google Doc attached to the Google Classroom post. The log is to include the work you completed, any AI usage and track your progress.

## Repository Structure
The initial structure is shown below. You are able to add files and folders. 
You cannot delete or move the initial files or folders.
```text
my_game/
├── .github/             <--- GitHub settings
├── .vscode/
│   └── settings.json  <--- settings for the project
├── assets/            <--- Folder for your assets (Don't put any in here)
│   ├── images/        <--- Folder for your images
│   ├── sounds/        <--- Folder for your sounds
│   └── fonts/         <--- Folder for your fonts
├── .gitignore         <--- This file helps keep unnessecary files off GitHub
├── main.py            <--- Main game file
├── README.md          <--- This file which provides basic instructions
```

## Game Starter Codes
These files have been provided to you to help start your game off. These instructions are on Google Classroom.
You must modify, change, extend the code given.

The starter codes use simple shapes generated by PyGame. Where in the actual project, you must use your own created images and sounds. 

The instructions provided gives you a lot of information about what you can add to your game such as enemies, effects, bosses, etc.
